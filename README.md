# Registration Page

This repository contains a Node.js project for managing user registrations. It includes a simple server, HTML views, and JSON files for storing registration data.

## Project Structure

- `index.html` — Main landing page
- `view.html` — View registrations page
- `server.js` — Node.js server handling requests
- `registrations.json` / `registeration.json` — JSON files for registration data
- `package.json` — Project metadata and dependencies

## Getting Started

1. **Install dependencies**
   ```powershell
   npm install
   ```
2. **Run the server**
   ```powershell
   node server.js
   ```
3. **Access the app**
   Open your browser and go to `http://localhost:3000` (or the port specified in `server.js`).

## Features

- Register new users
- View all registrations
- Data stored in JSON files

## Requirements

- Node.js (v14 or higher recommended)
